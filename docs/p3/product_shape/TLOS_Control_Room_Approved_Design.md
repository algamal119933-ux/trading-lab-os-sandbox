# Trading Lab OS — P3 Control Room
## Approved Visual Direction / الاتجاه البصري المعتمد

Status: APPROVED / FINAL VISUAL REFERENCE
Date: 2026-09-24

Approved reference: Third professional mockup generated in the current conversation.

## Design family
Trading Lab OS — Governed Control Room

## Core visual principles
- Dark-mode first.
- Calm, premium, technical, trustworthy, precise.
- Operations-control-room hierarchy before performance.
- Not a crypto exchange clone.
- Not a retail buy/sell app.
- Not casino-like or cyberpunk.
- Bilingual Arabic + English.
- Full RTL in Arabic and LTR in English.

## Primary information hierarchy
1. System truth / صحة النظام
2. Runtime and authority state / حالة التشغيل والصلاحيات
3. Current decision / القرار الحالي
4. Risk state / حالة المخاطر
5. Market context / سياق السوق
6. Positions and trades / المراكز والصفقات
7. Performance / الأداء
8. Evidence and reconciliation / الأدلة والمطابقة

## Core screens
- Command Center / مركز التحكم
- Market Workspace / مساحة السوق
- Decisions / القرارات
- Trades & Positions / الصفقات والمراكز
- Risk & Authority / المخاطر والصلاحيات
- Evidence & Reconciliation / الأدلة والمطابقة
- Incidents / الحوادث
- Operations / التشغيل
- History / التاريخ
- Settings / الإعدادات

## Required operator states
- HEALTHY
- DEGRADED
- INCIDENT
- RECOVERING
- STOPPED
- FAIL-CLOSED

## Authority treatment
- PAPER MODE must be explicit and prominent.
- REAL MONEY AUTHORIZED = NO must remain explicit.
- Kill Switch must be visually isolated and safety-oriented.
- The UI is an operator surface, not trading authority.

## Implementation boundary
This approval freezes the visual direction only. Production implementation remains gated by P3 authorization after P2 closure and final P2→P3 reconciliation.
