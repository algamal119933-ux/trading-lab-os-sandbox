# C0.2 — Secret and artifact hygiene

## Verification performed

`scripts/verify_repo.py` runs on every push and is covered by
`tests/test_repo_hygiene.py`. It checks, over tracked files only:

* **no secret material** — private key blocks, GitHub tokens, AWS key ids, Slack
  tokens, `sk-` API keys, JWTs, non-empty `"secret"`/`"key"` JSON fields;
* **no local-only artifact** — `.env`, runtime `config.json`, `*.sqlite*`,
  market-data directories, `*.feather`/`*.parquet`, logs, model directories,
  hyperopt results, MLflow state, key files, binary archives;
* **every tracked JSON and YAML parses**;
* **`MANIFEST.txt` lists exactly the tracked files with current hashes.**

A line may carry the marker `allowlist-secret` to declare a deliberate detector
fixture. Only `tests/test_repo_hygiene.py` uses it today.

Git history was also scanned: the repository has a single root commit and no
forbidden path has ever been added (`tests/test_repo_hygiene.py::test_git_history_never_carried_a_secret_bearing_path`).

## Artifact classification

Generated files are not deleted merely for being generated. Each is classified:

| Path | Class | Tracked? | Why |
| --- | --- | --- | --- |
| `freqtrade/user_data/baseline_v1_data_audit.json` | **Reproducibility evidence** | yes | The dataset integrity proof behind `DATA_INTEGRITY_GATE = PASS`. Historical (owner's machine); re-verifiable with `scripts/audit_data.py`. |
| `freqtrade/user_data/baseline_v1_passive_benchmarks.json` | **Reproducibility evidence** | yes | The development-window passive benchmark a candidate must be judged against. Development period only — validation and OOS are not present, by design. |
| `freqtrade/user_data/TRADING_LAB_OS_BASELINE_V1_PATCH_v1.3_2026-09-06.md` | **Decision record** | yes | Records why the benchmark script stopped printing OOS. |
| `docs/REVIEW_REPORT_2026-09-05.md` | **Decision record** | yes | Prior static review, explicitly "runtime hold". |
| `research/records/EXAMPLE_experiment_record.json` | **Schema reference instance** | yes | Marked `INFORMATIONAL`; carries historical numbers and says so. Never gate evidence. |
| `research/datasets/dataset_v1.lock.json` | **Freeze artifact** | yes | Pins dataset fingerprints and protocol windows. |
| `MANIFEST.txt` | **Deterministic check** | yes | Generated; verified in CI. |
| `.env` | Runtime secret | **no** | Local credentials. |
| `freqtrade/user_data/config.json` | Runtime state | **no** | Generated from the example; committing it would create a second source of truth. |
| `freqtrade/user_data/data/**` | Market data | **no** | Reproduced via `scripts/download_data.sh`, pinned by the dataset lock. |
| `*.sqlite*`, `logs/`, `mlruns/`, `models/`, `backtest_results/`, `hyperopt_results/` | Runtime state | **no** | Regenerated by running the stack. |
